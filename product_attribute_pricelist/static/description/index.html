Pricelist on Product Attribute

Apply smart pricing rules and discounts directly on product template attributes (like size or color) instead of managing every single variant manually.

Overview & Key Features

1

Attribute-level Targeting

Apply customized price rules or percentage discounts to specific product attributes (e.g., all XL-sized items, or all red variants) in one step.

2

Template & Variant Sync

Works seamlessly with existing Odoo pricelist workflows. Fully compatible with standard formula, fixed price, and percentage calculations.

3

Zero Overhead

Utilizes optimized database queries matching standard template structures, ensuring maximum performance even with thousands of products.

Real World Business Case

Example: A shop sells T-Shirts for $23. On Black Friday, they want to sell all XL size shirts for $20, regardless of the color (Red, Blue, Green, etc.).

Without This Module

You have to create a separate pricing rule for every single variant combination (T-Shirt Red XL, T-Shirt Blue XL, T-Shirt Green XL, etc.). If you add a new color, you have to add a new rule.

With This Module

You create exactly one rule applying on the "XL" attribute of the "T-Shirt". All current and future color variants matching the XL size will automatically use the discounted price.

How It Works

1

Select Apply Option

Open any Pricelist, click "Add a line" to create a rule, and choose "Product Attribute" in the "Apply To" field.

2

Choose Template and Attribute

Select your Product Template, then pick the specific Attribute Value (e.g. XL). The dropdown filters automatically based on the chosen template.

3

Configure Price & Calculate

Set the price type (Fixed, Discount, or Formula). When a customer buys any variant with the selected attribute, Odoo instantly applies the price.
