Odoo Gemini AI Integration

Intelligent AI assistant connected to your Odoo Database

This module integrates Odoo with Google's powerful Gemini AI models. It provides a secure setup page to register API keys and select models, and offers an intelligent chat assistant that has real-time access to database context (Products, Taxes, Partners, Purchase Orders) to guide, answer, and organize your work in beautifully formatted tables.

Key Features

Interactive Chat Wizard

Chat directly with Gemini AI inside Odoo using a scrollable history dialog.

RAG Database Connection

AI has access to products, prices, taxes, and POs to answer business questions accurately.

HTML Table Formatting

Converts markdown answers into native, clean, responsive Odoo tables automatically.

Secure Configuration

Store your API keys safely in Odoo General Settings with access control rules.
