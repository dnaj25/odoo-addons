Sales Product Labels

Print price and barcode labels for products directly from your Quotations or Sales Orders. Quantities can be automatically calculated from ordered lines.

Email Support WhatsApp Chat

Overview & Features

1

Print Directly from Orders

Generate labels from the Sales Order list view (multi-selection) or inside any Sales Order form view with one click.

2

Ordered Quantities Sync

Select "Ordered Quantities" to set the label count automatically matching the quantity ordered in the sales lines.

3

Full Layout Compatibility

Fully supports all built-in Odoo layout grids (Dymo, 2x7, 4x7, 4x12, custom, and ZPL formats) and price options.

How It Works

1

Select Orders & Print

Go to Sales -> Orders, select one or more orders, and choose "Print Custom Product Labels" from the Action menu.

2

Choose Quantity Method

In the layout wizard, choose "Ordered Quantities" to pull numbers automatically from lines, or "Custom" to set copies manually.

3

Generate Labels

Choose your sheet format and click Print. Odoo generates the PDF report ready to print on your label printer.
