Accounting Bank Counterparty Report

Real-Time Incoming & Outgoing Cash Flow Analysis with Partners and Offset Accounts

This module provides a detailed accounting report for all bank receipts and payments. It analyzes posted journal entries automatically to match bank lines with their counterparties (partners/accounts), helping accountants immediately track where incoming funds originated and where outgoing payments were directed.

Key Features

Interactive List Report

View transaction dates, journal names, bank accounts, counterparties (partners), offset accounts, references, and amounts.

Flexible Pivot Analysis

Summarize and group cash flow dynamically by Partner, Bank Account, or Counterparty Account.

Multi-Currency & Split Support

Handles complex, split transactions and multi-line invoice reconciliations accurately.

Robust SQL View Engine

Generates reports instantaneously directly via database SQL views, without slowing down your system.
